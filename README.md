

# Cinema Industry Trends 2015–2025 - Python Analysis

## Overview
This project analyzes cinema industry trends between 2015 and 2025, with emphasis on the effects of the COVID-19 pandemic on movie performance and industry patterns.

## Tools Used
- Python
- Pandas

## Project Focus
- Cleaning and exploring movie industry data
- Analyzing trends in budgets, revenues, profitability, and popularity
- Comparing pre-pandemic, pandemic, and post-pandemic eras

## Files Included
- Jupyter Notebook (project2.ipynb)
- Raw dataset (movies.csv)

## Key Skills Demonstrated
- Data cleaning
- Exploratory data analysis
- Trend analysis
- Python-based reporting
